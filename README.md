### WEBHAWK – Phishing and Fake Website Detector

**WEBHAWK** is a web-based phishing and fake website detection system developed using **Python, Flask, HTML, and CSS**. The system analyzes a given website URL and identifies whether it is **legitimate or potentially phishing** based on various URL characteristics and security-related patterns.

The application provides a simple and user-friendly interface where users can enter a URL and instantly receive a detection result. It also maintains a **history of recently checked URLs** and provides features such as **dark mode** for improved user experience. The project is deployed as a live website using **Flask**, making it accessible through a web browser.

**Technologies Used:** Python, Flask, HTML, CSS
**Type:** Web Application
**Deployment:** Live Web Deployment
**Key Features:** URL analysis, phishing detection, result classification, checking history, and user-friendly interface.
